# 手机充电头评测技能

基于功率、协议兼容性、体积、纹波四个维度的充电头综合评测数据查询。

---

## 评测维度

| 维度 | 说明 | 权重 | 评估标准 |
|------|------|------|----------|
| **充电功率** | 最大输出功率 (W) | 30% | 功率越高越好 |
| **协议支持** | 支持的快充协议 | 25% | 协议越多越好（PD/PPS/QC/AFC/VOOC/SCP） |
| **体积大小** | 尺寸体积 (cm³) | 20% | 越小越好 |
| **纹波大小** | 输出纹波 (mV) | 25% | 越低越好（<30mV 为优秀） |

---

## 评分规则

**综合评分 = 功率得分×0.3 + 协议得分×0.25 + 体积得分×0.2 + 纹波得分×0.25**

### 单项得分计算

**功率得分：**
- 100W+：100分
- 65-99W：80分
- 45-64W：60分
- 30-44W：40分
- <30W：20分

**协议得分：**
- 6+ 协议：100分
- 4-5 协议：80分
- 2-3 协议：60分
- 1 协议：40分

**体积得分：**
- <40cm³：100分
- 40-60cm³：80分
- 60-80cm³：60分
- >80cm³：40分

**纹波得分：**
- <20mV：100分
- 20-30mV：80分
- 30-50mV：60分
- >50mV：40分

## 品牌特点

| 品牌 | 优点 | 缺点 |
|------|------|------|
| **Anker** | 功率密度高，纹波低，协议全 | 价格偏高 |
| **小米** | 性价比高，协议兼容广 | 纹波控制一般 |
| **苹果** | 纹波极低，做工优秀 | 仅 PD 协议，体积大 |
| **绿联** | 性价比好，稳定可靠 | 功率密度一般 |
| **倍思** | 体积小，价格便宜 | 纹波略高 |
| **华为/OPPO** | 私有协议兼容好 | 第三方协议支持有限 |

## 选购建议

### 按场景推荐

| 场景 | 推荐型号 |
|------|----------|
| **多设备用户** | Anker 737 100W |
| **性价比首选** | 小米 GaN3 65W |
| **MacBook 用户** | 苹果 96W / 70W |
| **便携出行** | 小米 GaN3 65W / 倍思 65W |
| **快充协议多** | Anker / 绿联 |
| **预算有限** | 倍思 / 紫米 |

### 注意事项

1. **纹波低于 30mV 为优秀**，对电池寿命更好
2. **氮化镓 (GaN) 充电器**体积更小，但发热略高
3. **私有协议**（华为 SCP、OPPO VOOC）需要原装充电器才能满功率
4. **PD 3.1** 协议支持更大功率，但需要设备兼容
