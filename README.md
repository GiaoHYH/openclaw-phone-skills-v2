# OpenClaw 手机评测技能 + GitHub 镜像加速

本仓库提供以下技能：

| 技能 | 说明 |
|------|------|
| phone-charger | 手机充电头评测 |
| phone-review | 手机专业评测 |
| github-mirror | GitHub 镜像加速下载 |

---

## 🚀 快速安装

在机器上执行：

```bash
curl -fsSL https://skillhub-1388575217.cos.ap-guangzhou.myqcloud.com/install/skillhub.md 2>/dev/null | bash || \
curl -fsSL https://lightmake.site/skills/phone/install.sh | bash
```

或者手动安装：

```bash
# 克隆仓库
git clone https://ghproxy.com/https://github.com/GiaoHYH/openclaw-phone-skills-v2.git /tmp/openclaw-skills

# 复制技能
cp -r /tmp/openclaw-skills/phone-charger /你的openclaw路径/skills/
cp -r /tmp/openclaw-skills/phone-review /你的openclaw路径/skills/
cp -r /tmp/openclaw-skills/github-mirror /你的openclaw路径/skills/

# 重启
sh /path/to/openclaw/scripts/restart.sh
```

---

## 📖 技能说明

### phone-charger
手机充电头评测，从功率、协议、体积、纹波四个维度分析。

### phone-review
手机专业评测，从续航、影像、性能、屏幕、外观、性价比 6 个维度分析。

### github-mirror
GitHub 镜像加速，自动将 GitHub URL 转换为加速链接下载。
